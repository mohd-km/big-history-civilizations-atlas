# Big History & Civilizations Atlas

Live: https://history.mohammed-km.in/

13.8 billion years, from the Big Bang to today, on one zoomable screen, and a simple model of how energy, openness and shocks decide whether a civilisation grows or collapses.

Split out of Civilization & Futures Atlas (future.mohammed-km.in) on 28 November 2026 so every project covers one clear subject.

## Run locally

```bash
npm install
npm run dev
npm run build
```
